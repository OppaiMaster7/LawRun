# Mod page screenshots

1920×1080, GUI scale 3, taken in game by `./gradlew runClientGameTest -Pmodpage`
(a scripted run in a seeded world, `ModPageShots.java`). Run it again after a
visual change and the whole set is retaken the same way.

Suggested gallery order, with the first as the featured image:
**01, 15, 05, 08b, 13, 03, 06, 16, 18**, then the rest.

| Image | Description |
|---|---|
| `01-intro.png` | The six laws, dealt onto the table as paper cards at the start of every run. Click one to read more. |
| `02-disclaimer.png` | Every run opens with a disclaimer: a fan-made game adaptation of GuyBordo's video, not a history lesson. |
| `03-law-page.png` | Each law has its own page: the real law, how the run enforces it, how to survive it, and a link to that moment in the video. |
| `04-welcome.png` | Join a world and the mod greets you. Press T and click START. |
| `05-sunset.png` | Sunset: bells toll, the CURFEW banner drops, and a notice explains what counts as shelter. |
| `06-get-inside.png` | Caught outside after dark: a red pulse, a heartbeat and three seconds to get back in. |
| `07-sheltered.png` | Sheltered for the night, doors shut. The plate counts down to sunrise. |
| `08a-day-card.png` | Every sunrise opens with a newsreel title card. |
| `08b-confiscation.png` | Then everything you carried is confiscated and flies out of your hotbar. Three random pieces of food are handed back. |
| `09-rule-1.png` | Rule #1: the crafting table shows a banned weapon, but won't let you take it. |
| `10-safe-pocket.png` | The safe pocket: one extra slot whose stack survives sunrise. |
| `11-border.png` | Walk up to the border and a notice explains the travel permit. The tracker counts your diamonds. |
| `12-permit.png` | Three diamonds buy a travel permit. APPROVED. |
| `13-safe-chest.png` | Chests the world generated are stamped SAFE. Weapons are marked red: picking one up ends the run. |
| `14-trade.png` | Trading is banned. Looking is fine; taking a trade ends the run. |
| `15-arrest.png` | Break a rule and the world drains to grey as the rule card is stamped BROKEN. |
| `16-run-over.png` | The RUN OVER screen: your stats, and GuyBordo's for comparison. |
| `17-victory.png` | The dragon dies: RUN COMPLETE. |
| `18-record.png` | The exit portal plays the mod's own ending instead of the End Poem, starting with the record of your run. |
| `19-epilogue.png` | The ending closes quietly: the laws in this run were real. |

When writing the mod page text, keep to the project's ground rules:
- Credit GuyBordo and link his video.
- Say plainly that it's a game adaptation.
- Say it's unofficial: not affiliated with or endorsed by him.
- Don't use his branding as the mod's name until he agrees.
